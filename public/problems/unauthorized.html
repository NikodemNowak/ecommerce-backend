401

Unauthorized

Brak autoryzacji

Opis błędu

Żądanie wymaga uwierzytelnienia użytkownika. Podane dane logowania są nieprawidłowe lub token dostępu wygasł/jest nieprawidłowy.

Najczęstsze przyczyny

  • Nieprawidłowa nazwa użytkownika lub hasło
  • Brak nagłówka Authorization w żądaniu
  • Token JWT wygasł
  • Token JWT jest nieprawidłowy lub został zmodyfikowany
  • Użytkownik nie istnieje w systemie

Przykład prawidłowego żądania z tokenem

GET /orders
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Jak naprawić?

  • Sprawdź poprawność danych logowania
  • Upewnij się, że token jest przekazywany w nagłówku Authorization
  • Jeśli token wygasł, użyj endpointu /refresh aby uzyskać nowy
  • W razie problemów, zaloguj się ponownie przez /login
