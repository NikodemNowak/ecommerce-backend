409

Conflict

Konflikt zasobów

Opis błędu

Żądanie nie może zostać wykonane z powodu konfliktu z obecnym stanem zasobu. Najczęściej oznacza to próbę utworzenia duplikatu lub naruszenie ograniczeń unikalności.

Najczęstsze przyczyny

  • Próba rejestracji z nazwą użytkownika, która już istnieje
  • Próba utworzenia produktu z już istniejącym kodem SKU
  • Próba utworzenia kategorii o nazwie, która już istnieje
  • Konflikt wersji przy równoczesnej edycji zasobu

Przykład

POST /register
{ "username": "jan_kowalski", "password": "..." }

Odpowiedź: 409 Conflict
{ "detail": "Username already exists" }

Jak naprawić?

  • Wybierz inną, unikalną wartość (np. inną nazwę użytkownika)
  • Sprawdź, czy zasób o podanych danych już nie istnieje
  • Przy konfliktach wersji – pobierz najnowszą wersję zasobu i ponów operację
