422

Validation Error

Błąd walidacji danych

Opis błędu

Serwer rozumie składnię żądania, ale nie może go przetworzyć z powodu błędów semantycznych. Dane są syntaktycznie poprawne (prawidłowy JSON), ale nie spełniają wymagań biznesowych.

Różnica między 400 a 422

  • 400 Bad Request – błąd składni (np. nieprawidłowy JSON, brakujące pole)
  • 422 Unprocessable Entity – błąd semantyczny (np. email w złym formacie, cena ujemna)

Najczęstsze przyczyny

  • Nieprawidłowy format adresu email
  • Hasło zbyt krótkie lub nie spełniające wymagań
  • Cena produktu ujemna lub zerowa
  • Data w przeszłości, gdy wymagana jest przyszła
  • Wartość spoza dozwolonego zakresu

Przykład

POST /products
{ "name": "Laptop", "price": -100 }

Odpowiedź: 422 Validation Error
{ "detail": "Price must be a positive number" }

Jak naprawić?

Sprawdź szczegóły błędu w odpowiedzi API – pole detail zawiera informację o tym, które pole jest nieprawidłowe i dlaczego.
