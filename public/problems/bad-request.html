400

Bad Request

Nieprawidłowe żądanie

Opis błędu

Serwer nie może przetworzyć żądania z powodu błędnej składni lub brakujących wymaganych danych. Żądanie wymaga poprawienia przed ponownym wysłaniem.

Najczęstsze przyczyny

  • Brakujące wymagane pola w ciele żądania (np. username, password)
  • Nieprawidłowy format danych (np. tekst zamiast liczby)
  • Nieprawidłowa składnia JSON
  • Wartości poza dozwolonym zakresem

Przykład błędnego żądania

POST /login
Content-Type: application/json

{ "username": "" } ← brak hasła

Jak naprawić?

Sprawdź dokumentację API i upewnij się, że wszystkie wymagane pola są wypełnione prawidłowymi wartościami.
