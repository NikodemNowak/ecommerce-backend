404

Not Found

Zasób nie znaleziony

Opis błędu

Żądany zasób nie istnieje na serwerze. Może to dotyczyć produktu, zamówienia, kategorii lub innego obiektu o podanym identyfikatorze.

Najczęstsze przyczyny

  • Produkt o podanym ID nie istnieje lub został usunięty
  • Zamówienie o podanym ID nie istnieje
  • Nieprawidłowy endpoint API
  • Literówka w URL

Przykład

GET /products/99999

Odpowiedź: 404 Not Found
{ "detail": "Product not found" }

Jak naprawić?

  • Sprawdź, czy ID zasobu jest prawidłowe
  • Upewnij się, że zasób nie został usunięty
  • Sprawdź poprawność URL endpointu
  • Zobacz dokumentację API dla listy dostępnych endpointów
